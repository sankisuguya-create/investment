投資指標ワークベンチ 用語集（素人向け）
==================================================

■ まず大筋：このツールは「値動きを説明する変数」をデータから探す道具です。
　指標（変数）→ 相関（IC）→ 過去検証 → ストラテジー、の順で進みます。

--------------------------------------------------
【市場データ】
--------------------------------------------------
・日経平均 …… 日本の代表的な株価指数。225社の平均。
・日経平均VI …… 「恐怖指数」。日経先物の変動予想度。高い＝市場が不安。
　　ブログの例（米国VIXが高い日の翌日は戻りやすい）の日本版として使える。
・VIX …… 米国版の恐怖指数。S&P500版。
・終値（おわりね）… その日の最後の価格。分析は基本的に終値を使う。
・リターン（騰落率）… 前日から何%動いたか。+1.2% など。
・リターン期間 … 何日先のリターンを説明するか。「翌日」= 今日の指標→明日の動き。
・取引日（営業日）… 市場が開いている日。土日祝はデータがない。
・欠損補完 … 米国休場で日本だけ動いた日など、欠けた値を直近の値で埋める設定。

--------------------------------------------------
【統計・分析】
--------------------------------------------------
・指標（インジケーター）… 値動きを説明するかもしれない変数。VI・移動平均乖離・RSI等。
・IC（情報係数）… 指標とリターンの相関係数。−1〜+1。
　　|IC| ≥ 0.05 … 優秀　|IC| ≥ 0.1 … 非常に優秀（ブログの基準）
　　※マイナスでもOK＝「指標が高いと下がる」＝逆張りとして使える。
・RankIC … ICの頑健版。外れ値（異常な日）に左右されにくい順位ベースの相関。
・p値 … 「その相関が偶然だった確率」に近いもの。0.05（5%）未満で有意とみる。
　　ICがあってもp値が大きい＝偶然の可能性。両方見ることが必須。
・R²（決定係数）… リターンの変動の何割を指標で説明できるか。0.05=5%。小さくて当然。
・散布図 … 横軸=指標、縦軸=リターンの点プロット。まず形を目で見る。
・回帰直線 … 散布図に引く「だいたいの傾向線」。±1.96σ帯は点の95%が入る目安幅。
・Zスコア … 「平均0・ばらつき1」に換算した値。+2なら平均よりかなり高い、の感覚。
　　指標同士を同じ物差しで比べたり、閾値（Z>1で買い等）に使う。
・分位別（10群）… 指標の大きさで10グループに分けた時の各平均リターン。
　　Q1(低)→Q10(高)へ「階段状」に増える（減る）のが素性の良い指標。
・ヒストグラム（分布）… 値の偏りを見る。極端な外れ値だらけだと相関が嘘をつく。
・ローリングIC … 60日窓で切ったICの推移。一時期だけ効く指標を見破るためのもの。
・累積リターン（資産曲線）… その指標のルールで売買した場合の資産の増え方。
・最大ドローダウン（最大DD）… 資産曲線の山から谷への最大下落率。最悪の含み損。
・レジーム分割 … 条件変数（例:VI）の高い時期・低い時期で分析を分ける機能。
　　「VIが高い時だけ効く」ような交互作用の発見用。
・Welchのt検定 … 「イベント日の平均」と「全日の平均」の差が偶然かを検定する。
　　p値0.05未満なら有意な差の可能性。

--------------------------------------------------
【イベント（発表カレンダー）】
--------------------------------------------------
・経済指標発表 … CPI・雇用統計・金利発表など、決まった日時に出る公式数字。
・FOMC … 米国の金融政策決定会合。金利発表は世界の市場が注目。
・日銀会合 … 日本版。BOJ Monetary Policy。
・予想（コンセンサス）… 市場予想値。発表「前」に織り込み済みの数字。
・結果（実績）… 実際に発表された数字。
・サプライズ … 結果−予想。これこそが価格を動かす主因。
　　発表の内容より「予想を上回ったか下回ったか」が効く。
・イベント集計 … 発表日のリターン平均を、全日平均と比べる分析。
　　イベントは「点」なのでICよりもこの集計が向いている。
・重要度 … カレンダーの低/中/高。「高」だけに絞るのが実用的。
・時差 … 米国発表（夜間）→日本株には「翌日」側に効くことが多い。
　　日本発表（東京時間）→日本株には「当日」側。
・取込と蓄積 … 週次カレンダーXMLを毎週取込むと2023年以降を積み上げられる。

--------------------------------------------------
【ストラテジー評価】
--------------------------------------------------
・ロング / ショート … 買い持ち / 売り持ち（下がると儲かるポジション）。
・期待成長率 e … 1トレードあたりの平均リターン。
・標準偏差 σ … 1トレードのばらつき。
・e/σ … シャープレシオ相当。大きいほど効率よく儲かる。
・トレード数 N … 取引の回数。少なすぎると検証にならない、多すぎると薄い。
・バックテスト … 過去データでの成績検証。未来の保証ではない。
・目標との照合 … 推定年率が目標利回りを、最大DDが許容DDを、超えないかの確認。

--------------------------------------------------
【買い時（長期投資の暴落買い）】
--------------------------------------------------
・買いシグナル … 条件（例：VIのZ≥1.5 かつ 高値から−10%超）をすべて満たす日。
・エピソード … 連続するシグナルを1回の「買い場」としてまとめたもの。
・高値からの下落率 … 直近N営業日の最高値から何%下げているか（常時0以下）。
・シグナル後リターン … エピソード開始日から20日・60日・125日・250日後の騰落。
・分割購入 … 暴落は底が読めないため、枠を分けて買い下がる方法（初回1/3など）。
・コア/サテライト … 積立（コア）は止めず、暴落買いは別枠（サテライト）で行う考え方。

--------------------------------------------------
【落とし穴（ブログの教訓）】
--------------------------------------------------
・カーブフィッティング（過剰適合）… 過去に合わせすぎた指標は未来で効かない。
　　対策： 採用指標は1〜3個まで、パラメータを増やしすぎない。
・データスヌーピング … 何度も試行錯誤して偶然見つけた「効く指標」。
　　対策： 「なぜ効くか」の因果仮説（演繹メモ）を必ず書く。
・区間切出し … たまたま良かった時期だけを拾うのは完全なカーブフィッティング。
　　全期間の累積リターンとローリングICで確認する。
・タイプⅠエラー … 偶然なのに「有意」と判定する誤り。p値の確認が対策。

--------------------------------------------------
【指標の種類（ツール内）】
--------------------------------------------------
・CSV列のまま … 取込んだ列（例：VIの終値）をそのまま指標に。
・移動平均乖離率 … 終値÷25日平均−1。株価が平均から離れすぎた度合い（逆張り系）。
・騰落率（モメンタム）… N日前からの変化率。勢い。
・ボラティリティ … リターンのばらつき（N日標準偏差）。荒さ。
・RSI … 0〜100の買われすぎ/売られすぎ指標。
・イベント・サプライズ … 発表の「結果−予想」を正規化した値。
・イベント・当日ダミー … 発表日=1の0/1値（集計とセットで見る）。
・イベント・次回まで/前回から日数 … 発表の近さを数値化した指標。

--------------------------------------------------
【データ管理】
--------------------------------------------------
・CSV … カンマ区切りの表データ。Excelでも開ける。
・Shift-JIS … 日本語CSVの文字コード。日経公式CSVはこれ（自動対応済み）。
・localStorage … ブラウザ内の保存場所。閉じてもデータが残る。
・JSON書出/読込 … 設定・指標・メモを1ファイルに書出して退避・復元する機能。
